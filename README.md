# ХУЕ / Полусон

Цветовая головоломка для Android/RuStore и Яндекс Игр. Подготовка реализации по ТЗ 1.0 от 18 ноября 2026.

Работа начинается с M0: воспроизводимые платформенные сборки, точные runtime/guidance pins mini-games-kit и ранняя проверка внешних зависимостей. Полный scope и приёмка переносятся в репозиторий вместе с первой технической базой.

Продукт пока не выпущен. «Полусон» — рабочее название.
