**Локальный пакет в 0.4.12.** «Прогресс» показывает кампанию, главы, первые победы и XP. Видны завершение последнего уровня главы и полный сбор главы. История сохраняется одной операцией с победой, а настройка статистики переживает перезапуск. Сравнения и десять ступеней готовы к проверке с версионированной выборкой реальных проходов. Опубликованной выборки пока нет. [Проверки](../evidence/player-progress-2026-11-20.json)

Сохранить различие между лучшим личным результатом, теоретическим минимумом и сравнением с другими игроками. Ввести историю попыток, счётчик подходящих сравнений и десять ступеней мастерства. Для оригинальной линейки Hue подтверждены пороги 2/5/10/20/50/100/150/200/250/300 и строгое сравнение результата со средним. Исторические средние конкурента не импортировать. Для нашего поля публиковать происхождение, размер выборки и версию эталона. Пока выборки нет, доступны личные и математические цели, счётчик побед над средним ожидает данных. Проектное правило для тестового среза — засчитывать одну завершённую подходящую попытку один раз, результаты с помощью отдельно. Учесть флаги набора, категорию, открытие главы, отдельные очки опыта и переключатель отображения статистики. Проверки: равенство эталону, на один ход лучше, повтор результата, дубль callback, офлайн и смена эталона. Показать, чем достижение за последний набор отличается от полного сбора категории.

Очередность — после 01.

Добавить отдельный вход в испытания с лимитом ходов и собственным банком стартов. Банк Color содержит десять испытаний, доступ с 10…100 сердец; это источник структуры. Для нашей кампании с 60 задачами не вводить недостижимый порог в 100 кампанийных побед. Сначала подключить десять тестовых профилей с нужным прогрессом, затем подобрать нашу шкалу по фактически доступным уникальным задачам. Порядок проверки хода — применить легальный обмен, проверить победу, затем исчерпание лимита. Три независимых расширения: испытание главы после завершения обычных задач; скрытие подвижных цветов при первом показе с открытыми опорами; отдельная десятиминутная сессия последовательных полей. Для secret загрузка сохранённой партии сразу показывает рабочую раскладку. Для timed сохранять остаток и счёт при паузе. Записи для приёмки — последний допустимый ход в обоих исходах, повтор главы, resume secret, сворачивание во время таймера. Большие поля подключить после 04.

Сохранить неизменные первые 15, старые fingerprint и fixed-start replay. Для вариативной партии сохранять полученную перестановку и версию генератора. У каждой группы размером n один цикл даёт n−1; для произвольной перестановки считать циклы фактического старта. Добавить крупные прямоугольные поля, hex/tri и смешанные фигуры. Проверить попадание после pan/zoom, отпускание за краем, доступность опор и точные RGB. Метрика близости цветов остаётся измеримой проверкой контента; возможное влияние на выдачу Hue Too требует поиска вызывающего кода.

## 07. Редактор, передача игровых задач и сообщество

**E3, локальный контракт.** Подтверждённая ревизия и ID операции фиксируются до отправки. Повтор отправляет прежний файл и ID, квота считает принятые результаты, раздельно учтены модерация, отзыв и жалоба. [Проверки фикстуры](../evidence/queue-e3-2026-11-20.json). Сервис и публичный вход ожидают конфигурации.

**E2 в 0.4.24.** Проверенная ревизия экспортируется в отдельный играбельный файл с палитрой, закреплениями, началом и отпечатком. Импорт создаёт работу без чужого результата. В Chromium файл прежней версии прошёл после правки оригинала; повреждённый файл не меняет снимок, сохранённые обои использовали прежний точный RGB. [Контроль](../evidence/queue-e2-2026-11-20.json)

Очередность — локальный редактор доступен; сеть зависит от сервиса.

Расширять построенный редактор. Свои, прошедшие проверку автора и опубликованные задачи имеют разные состояния. Редактор доступен с начала; пороги Color 25/150 сохраняются как данные референса для постепенного открытия публичных действий. Дать передачу конкретной *играбельной* ревизии, импорт с валидатором, отдельную отправку на публикацию и ленту одобренных работ. Дедупликация и квоты по подтверждённой операции, жалоба/отзыв и безопасное отображение имени автора входят в контракт. Публичная версия не меняется от последующей правки черновика. Сценарии: пустой черновик, неподходящая к публикации работа, правка после проверки, повтор отправки при потерянном ответе, 15-я отправка и новый день, отзыв опубликованной ревизии. Пока внешний сервис недоступен, реализуются локальная передача, валидатор, состояния и воспроизводимые тесты.

## 09. Сохранения, учёт событий и соревнования

**F2, локальный протокол.** Намерение не равно принятому ходу. Для соревнования считать результаты только на сопоставимом fixed-start и одинаковой политике помощи. Протокол турнира, локальную проверку replay и ранжирование на fixtures можно делать сейчас. `h1-audio` · `h1-music`
