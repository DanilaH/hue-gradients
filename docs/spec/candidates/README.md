## Воспроизведение

Из корня этого датированного исследования, Python 3.12, только стандартная библиотека:

```sh
python tools/build_release_candidates.py --out candidates/levels-0.1.json
python tools/validate_release_candidates.py --pack candidates/levels-0.1.json --out candidates/validation-0.1.json --previews candidates/previews
python tools/check_editor_boundaries.py
```

Генератор использует собственные функции из build_prototype_pack.py. Новый validator **не импортирует генератор**: RGB заново вычисляются через Fraction и half-up; перестановки, опоры и симметрии проверяются отдельно. Cycle minimum, witness и BFS переиспользуются из независимого validate_prototype_pack.py; построенный witness дополнительно проигрывается. Для N уникальных подвижных плиток при произвольных обменах минимум равен N минус число циклов; у новых стартов один цикл. Это оптимум обменов, не модель поиска человеком.

## Происхождение и ограничения

Новые палитры параметрически получены из собственной схемы hue/lightness, а не из APK. Псевдослучайный старт и цвета сохранены явно. Скрипт не является генератором runtime-сложности; в клиенте authoritative — замороженный JSON.

Просмотрены листы 2–6 как точный raster-render тех же RGB и опор. SVG проверены как XML. Это не screenshot приложения и не оценка цветопередачи телефона. Лист 1 повторяет прежний baseline. PNG для локального просмотра — временные воспроизводимые материалы и не входят в банк.

Автоматическая проверка исключает точные одинаковые подвижные RGB, но близкие пары лишь помечает; выбранный порог 0.025 не является стандартом доступности. Геометрическая проверка охватывает симметрии прямоугольника/квадрата, не все возможные зрительные неоднозначности. Повторённый шаблон с новой палитрой не объявлен новой стратегией. Все 90 кандидатов ждут человеческой приёмки; четыре предупреждения требуют отдельного решения. До назначения UTC-дат daily не считаются опубликованными.

**Не исполнены:** UI, хранилище редактора, cloud, поставка daily, экспорт, телефонный тест, человеческий плейтест и retention. 33 проверки относятся только к чистому полю/fingerprint. Новых APK-запусков нет. Общие kit API не изменены.
