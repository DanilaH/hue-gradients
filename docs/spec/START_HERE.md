# ХУЕ / «Полусон» — пакет разработки 1.0

Подготовлено 18 ноября 2026. Это подробное ТЗ полного первого релиза и план его реализации. Исполняемой полной игры в архиве нет.

1. **PRODUCT_SPEC_1_0.md** — основной контракт: 71 требование, scope, правила и визуальный эталон.
2. **ROADMAP_1_0.md** — девять этапов M0–M8, зависимости, поставки и критерии готовности.
3. **ACCEPTANCE_MATRIX_1_0.md** — проверяемые эпизоды по каждому требованию. **acceptance-register.csv** — заполняемая таблица статусов и evidence.
4. **reference/owner-art-reference.png** — исходное изображение владельца без изменений. Это ориентир света/фактуры/композиции, не источник точных игровых RGB и не согласование прежнего шрифта.
5. Остальные SPEC и PROTOTYPE_BRIEF — технические приложения; основной документ явно разрешает старые расхождения. **candidates/** и **prototype/** содержат собственные данные и точные контактные листы.

Полный релиз включает кампанию, мету/альбом, daily/архив, редактор, экспорт, облако, платформенные адаптеры и рекламу по выбранной политике. Энергии нет. В текущем проходе выполнялась документация, live-проба и код игры не менялись.

Читать можно локально. Ссылки на не включённые архивные исследования и общие инструкции kit нормализованы на точный GitHub commit; им нужен доступ в репозиторий. Основное ТЗ, специальные контракты, изображение и данные находятся внутри архива.

## Проверка данных

Python 3.12, стандартная библиотека. Из корня распакованного архива, вывод в отдельную папку:

```sh
python tools/validate_release_candidates.py --pack candidates/levels-0.1.json --out verification/validation.json --previews verification/previews
python tools/check_editor_boundaries.py
```

Вторая команда обновляет только сохранённый отчёт editor-boundaries. Не запускать генераторы ради игры: клиент использует замороженные definitions. Они приложены для воспроизведения авторского банка.

При подготовке исправлена только baselineSha256 в метаданных банка: прежняя рабочая копия первых15 отличалась одним завершающим переводом строки. Все90definitions и dailySchedule неизменны. Повторно прошли90replay,26BFS,33editor checks. Протокол — evidence/package-integrity-repair-2026-11-18.json. Техническая модель54сценариев приложена как прежнее свидетельство, заново в этом проходе не исполнялась.

Полная игра/телефоны/реальный auth/cloud/SDK проходят будущую матрицу. NOT RUN в таблице нельзя заменять PASS по этим исследовательским проверкам.
