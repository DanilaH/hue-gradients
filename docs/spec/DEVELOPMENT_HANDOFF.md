Псевдопиксельный шрифт ранее отвергнут; новый шрифт ещё выбирается на реальных экранах. Браузерная проба подтверждает лишь часть ввода/реактивности, её плоский вид не заменяет референс. Сейчас visual renderer не менялся.

## С чего начать реализацию

M0: актуальный consumer/HEAD и kit pins, проверенный scaffold, реальные identity capabilities Android/Yandex Games, устройства и инфраструктурные gates. Затем M1: доменное ядро, точные первые15, input/cancel/help и SQLite/IndexedDB с подтверждённым commit. M2 принимает один художественный эпизод до распространения стиля на остальные экраны. Cloud backend может развиваться после закрепления схем параллельно с метой/редактором.

Не сокращать первый релиз до художественной пробы или15задач; не добавлять сезоны/валюту/public UGC ради полноты. Не считать generated concept, Node/Python tests или SDK mock проверкой physical touch, облака, рекламы и человеческого удовольствия.

## Имеющиеся доказательства

Ранее проверены90оптимальных replay,26BFS,33editor fixtures и54technical-model сценария. Браузерная проба на трёх задачах проверяла tap/drag, отмену, reload и победу. В текущем проходе проверены полнота ID/ссылок, scope и целостность пакета; исправлена ошибочная baselineSha256 в метаданных банка. Все90definitions неизменны;90replay,26BFS и33editor checks повторены успешно. 54technical-model сценария заново не исполнялись. Все production acceptance остаются по матрице.

Полный перенос между устройствами одного подтверждённого профиля обязателен. Автоматическое Android↔Yandex Games account linking по имени/email не обещается. Список gates/кто закрывает/когда — PRODUCT_SPEC §15; порядок доставки — ROADMAP.
