## Откуда берётся цвет

Простой средний цвет или гистограмма не реагируют на swap: набор RGB неизменен. Поэтому функция `spatial(level, order)` берёт девять пространственных проб из **текущей перестановки**. Для каждой позиции плитки и центра пробы считается Gaussian weight `exp(-distance² / 0.085)`; RGB усредняется с этими весами.

Фон непрерывен на весь viewport, независимо от прямоугольной доски. Его собственный blur не применяется к плиткам: активные поверхности непрозрачны, их RGB берутся прямо из `solvedTileColors[tileId]`. Захваченная плитка сохраняет этот цвет; маркеры pin/выбора — отдельная геометрия.

| Событие | Реакция |
| --- | --- |
| Покой | Очень медленное небольшое смещение цветовых пятен, без камеры и деформации сетки |
| Захват/drag | Оттенок взятой плитки мягко следует за координатой указателя; ghost следует напрямую |
| Законный swap | Новый пространственный фон плавно догоняет поле, постоянная времени 420 ms; короткий цветовой импульс у места посадки |
| Pin, отпуск за полем, cancel | Нет обмена/счётчика/награды; след жеста убирается |
| Явная помощь | Показывается решение после сохранения assisted; фон следует этому явно показанному состоянию |
| Победа | После успешного сохранения поле затухает за 650 ms, остаётся целостный фон из собранного расположения |
| Просмотр финала в меню | Явно помеченный просмотр, без записи победы и изменения попытки; отдельный возврат к партии |
| Движение выключено / system reduced motion | Нет дрейфа/импульсов, новый цвет рисуется статично |
| Меню / скрытая вкладка | Непрерывный рендер остановлен; при возврате без накопленного скачка времени |

Никакой зависимости эффекта от числа верных плиток, расстояния до решения, оптимума или «хорошего» хода. Любой законный swap получает одинаковую силу отклика. Так фон не становится скрытым индикатором правильного решения. Это проектное ограничение; явная помощь/финальный просмотр остаются доступными.

## Параметры и пределы

- Buildless HTML/CSS/JS, без внешних runtime-зависимостей.
- Фон: Canvas2D, максимум 180×250 внутренних пикселей и примерно 30 FPS, CSS blur 34 px. Это заданный бюджет, не измеренная скорость на телефоне.
- Дрейф: 0.055 ширины / 0.045 высоты нормализованного canvas, медленные синусоиды 0.22/0.18 rad/s. Импульс затухает с постоянной времени 1.25 s.
- Три точные собственные задачи: gradient-015, gradient-009, gradient-005. Исходные банки 15/90 не изменены.
- В телефоном layout поле занимает ширину, высоту между компактными верхом/низом; на desktop ширина ограничена 580 px. Это презентация пробы, не новая универсальная геометрия релиза. SafeLeft/SafeRight, SDK-баннер, text150%, плотные сетки и ориентации требуют production-проверки.
- Прогресс хранится только в этом браузере через localStorage, не переносится в будущую игру. Это не реализация транзакций/cloud из технического ТЗ.

`node check.cjs`: все три задачи прошли legality/pins, validation сохранения, неизменность среднего при swap одновременно с изменением пространственного фона, оптимальные replay 19/7/3. `node --check dist/app.js` прошёл. Эти проверки не измеряют эстетическое качество или удержание.

Полный релиз по-прежнему включает daily, редактор, облако и удержание; энергии нет.
